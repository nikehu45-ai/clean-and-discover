# 技术架构

## 技术栈

- Vite + TypeScript
- Three.js WebGL 渲染
- Vitest 清洁算法测试
- GitHub Pages 静态部署

## 模块

| 路径 | 职责 |
|---|---|
| `src/data/levels.ts` | 关卡、工具和污渍配置 |
| `src/game/mask.ts` | 污渍网格、规则扫掠、自动收尾 |
| `src/game/CleaningEngine.ts` | 输入、进度、扫描、完成状态 |
| `src/game/ThreeCleaningRenderer.ts` | 3D 场景、材质、工具、动态纹理 |
| `src/platform/storage.ts` | 本地存档与升级数据 |
| `src/main.ts` | 工作室、订单、HUD 和结算界面 |

## 本地命令

```bash
npm install
npm run dev
npm test
npm run build
```
