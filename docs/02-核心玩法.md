# 核心玩法

## 单局循环

接取订单 → 观察污染 → 选择工具 → 连续扫掠 → 发现隐藏物 → 清洁完成 → 获得金币与成长。

## 工具关系

| 工具 | 主要目标 | 特点 |
|---|---|---|
| 水枪 | 泥浆 | 宽喷覆盖大，集中喷效率高 |
| 吸尘器 | 灰尘、毛发 | 对织物和干燥污渍效率高 |
| 泡沫 | 油污预处理 | 需要等待软化 |
| 毛刷 | 已软化油污 | 与泡沫组成两阶段处理 |

## 清洁手感标准

- 相邻采样点之间由矩形条带连续连接。
- 笔画起点、终点和转折处由方形接缝补齐。
- 快速扫动不能因为帧率或指针采样留下空隙。
- 局部孤立污点自动消除。
- 达到 98.5% 后自动完成，玩家无需寻找最后几个像素。

## 成长系统

- 订单奖励金币。
- 工具升级扩大覆盖范围并提高效率。
- 完成订单逐步解锁工具、收藏品和工作室外观。
