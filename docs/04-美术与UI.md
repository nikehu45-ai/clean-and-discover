# 美术与 UI

## 视觉方向

- 清洁工作室使用低饱和青绿色、暖灰和旧物棕色。
- 物体采用可读性优先的程序化 3D 造型。
- PBR 材质、柔和阴影和轻雾营造正式 3D 空间。
- 污渍与泡沫使用动态纹理，清洁结果即时更新。

## 游戏界面

- 顶部：暂停、订单信息、金币、声音、重置。
- 右上：清洁度卡片。
- 中部：3D 清洁操作区域。
- 底部：四种工具、工具提示、喷头模式和污渍扫描。

## 一致性规范

- 主要圆角 16–24px。
- 强交互使用青色描边与浅蓝底。
- 污渍扫描使用暖橙色，不与清洁完成色混淆。
- 小屏优先保证操作区域与工具栏完整可见。
